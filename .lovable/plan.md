# План: белая карта в Android-приложении

## Что проверено
- Шаг вставки ключа в `AndroidManifest.xml` в `codemagic.yaml` существует и корректен — но если переменная `GOOGLE_MAPS_ANDROID_API_KEY` пустая, сборка НЕ падает, а только пишет WARNING, и приложение собирается без ключа → белая карта.
- `LocationMap.tsx` в нативном режиме передаёт пустой `apiKey` и рассчитывает на meta-data из манифеста — если ключа там нет или он невалиден, карта остаётся белой без понятной ошибки.
- Манифест в репозитории не содержит meta-data ключа — любая сборка вне Codemagic-шага собирается без ключа.

## Наиболее вероятные причины (по порядку)
1. Переменная `GOOGLE_MAPS_ANDROID_API_KEY` не задана/пустая в Codemagic (в логе сборки будет `WARNING: ... not set or empty`).
2. Ключ задан, но в Google Cloud ограничения ключа не совпадают: нужен пакет `app.lovable.umnilisenok` + SHA-1 keystore (он печатается в шаге «Print keystore SHA-1» в логе сборки).
3. Не включён **Maps SDK for Android** или не подключён billing в проекте Google Cloud.

## Что будет изменено в коде
1. **Codemagic: падать с понятной ошибкой, если ключа нет**
   - В обоих workflow шаг вставки ключа завершает сборку с ошибкой «GOOGLE_MAPS_ANDROID_API_KEY is not set», если переменная пустая — вместо тихой сборки с белой картой.
   - После вставки добавить проверку: grep meta-data в манифесте и падение, если тег не появился.

2. **Запасной вариант ключа через manifest placeholder**
   - В `android/app/build.gradle` добавить `manifestPlaceholders = [GOOGLE_MAPS_API_KEY: ...]` (из переменной окружения/gradle-свойства), а в `android/app/src/main/AndroidManifest.xml` добавить meta-data `${GOOGLE_MAPS_API_KEY}` — тогда ключ подставляется при любой сборке, не только в Codemagic.

3. **Диагностика в приложении**
   - `LocationMap.tsx`: при ошибке создания нативной карты показывать текст причины (нет ключа / нет сети) вместо белого блока, и логировать в консоль (видно через `adb logcat`).
   - Добавить таймаут: если карта не поднялась за ~8 секунд, показать сообщение об ошибке.

4. **Проверка**
   - Production web build + typecheck.
   - Симуляция шага вставки ключа локально (с тестовым значением) и проверка итогового манифеста.

## Что нужно будет проверить у пользователя (вне кода)
1. В логе последней сборки Codemagic найти строку `DEBUG: Found API Key length = ...` — если длина 0, переменная не задана.
2. В Google Cloud: Maps SDK for Android включён, billing подключён, в ограничениях ключа указаны пакет `app.lovable.umnilisenok` и SHA-1 из шага «Print keystore SHA-1».
3. После исправлений — `git pull` и новая сборка.
