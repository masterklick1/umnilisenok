# План: раздел «Чтение» — обучение по складам

## Цель
Добавить в детское приложение полноценный раздел «Чтение», где ребёнок 3–7 лет учится складывать слоги из букв и читать простые слова вслух с помощью TTS и аудиообратной связи.

## Что будет в первой версии

### 1. Экран выбора уровня
- 4 уровня сложности:
  1. **Гласные** (а, о, у, э, ы, и, е, ё, ю, я)
  2. **Простые слоги** (ма, па, ба, ка и т.д.)
  3. **Сложные слоги** (с буквосочетаниями: ль, нь, ст, ск)
  4. **Простые слова** (3–4 буквы: мама, папа, кот, дом)

### 2. Интерактивный урок
- Карточка с большой буквой/слогом/словом по центру.
- Кнопка «Послушать» (TTS `window.speechSynthesis` на русском).
- Режим «Собери слог»: буквы разбросаны, ребёнок перетаскивает/нажимает в правильном порядке.
- Режим «Выбери картинку»: 3 картинки, нужно выбрать ту, что соответствует слову.

### 3. Аудиообратная связь
- Верный ответ — радостный звук + похвала голосом.
- Ошибка — мягкий голосовой подсказ: «Попробуй ещё раз».

### 4. Прогресс и награды
- За каждый пройденный урок — звёзды в `user_progress`.
- Достижение «Первый слог», «10 слов», «Читатель».
- Синхронизация активности в `child_activity` для родительской панели.

### 5. Родительский кабинет
- Новая вкладка/карточка «Чтение» в `/parent`.
- Показывает: сколько слогов/слов освоено, последний уровень, рекомендации.

### База данных
- Новая таблица `reading_progress`:
  - `id`, `child_id`, `level`, `lesson_index`, `completed_at`, `stars_earned`, `attempts`.
  - RLS: ребёнок видит свой прогресс, родители — прогресс связанных детей.
- GRANT на таблицу для `authenticated` и `service_role`.
- Обновить `achievements` (добавить 3 ачивки для чтения).

### Интеграции
- `window.speechSynthesis` для произношения (уже используется в алфавите).
- `useActivityTracker` для синхронизации активности.
- `useUserProgress` для начисления звёзд и достижений.

## Критерии готовности
- [ ] Ребёнок может открыть раздел «Чтение» из главного меню.
- [ ] Ребёнок проходит уроки 4 уровней, получает звёзды и слышит слова.
- [ ] Родитель видит прогресс чтения в кабинете.
- [ ] Аудиообратная связь работает на верный/неверный ответ.
- [ ] Данные синхронизируются с Supabase в реальном времени.

## Вне рамок этой итерации
- Распознавание речи ребёнка (проверка произношения).
- Сказки с озвучкой.
- Индивидуальный ИИ-репетитор.
